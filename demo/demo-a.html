Demo Page A — Option B System

This page loads its menu and footer from shared partial files. Test the speed and feel of using this setup.

What's happening on this page

This page contains no menu HTML and no footer HTML in its file. Instead, when the page loads, a tiny JavaScript file fetches the menu from partials/menu.html and footer from partials/footer.html and inserts them.

⚡ The big advantage: If you need to change the menu later, you only edit partials/menu.html — and ALL pages that use this system update instantly. No more 36-page updates!

How to test the speed

1. Open this page on your phone (slow 3G if possible) — see if menu appears noticeably delayed.

2. Refresh the page a few times — second time loads from browser cache (instant).

3. Click between Demo A and Demo B (link below) — feel the difference.
