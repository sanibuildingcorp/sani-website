## ACTION PLAN — ranked by impact

### 1. Google Business Profile + reviews  ← #1 BY FAR (Zura owns this)
The Map Pack sits above all organic results; ~80% of local clicks go there. Driven by GBP + reviews + proximity (page content does NOT affect it).
- [ ] Add categories: **Bathroom remodeler, Flooring contractor, Handyman, Deck builder** (keep primary = General contractor)
- [ ] Add **Services** with borough keywords in descriptions (Bathroom Renovation Brooklyn, Kitchen Cabinet Installation Manhattan, etc.)
- [ ] Set **Service Areas** = 5 boroughs + Long Island/Nassau/Suffolk (offsets Brighton Beach proximity handicap)
- [ ] Post weekly (offers, finished jobs, photos) — use correct post type
- [ ] **Ask EVERY finished customer for a review** — dashboard has a one-tap "★ Ask This Customer for a Review" button. Reviews count + recency is a top map-pack factor. Currently ~63; competitors with more reviews outrank.
- [ ] Upload real job photos to GBP regularly
